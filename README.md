# Garagem Import

Sistema web de locação de carros importados desenvolvido com React, Vite e Tailwind CSS.
Checkpoint 6 - Web Development - FIAP 1ESPG.

## Funcionalidades

- Navbar com navegação entre páginas (react-router-dom)
- Home com hero, vantagens e carros em destaque
- Página Carros com a frota completa e filtro por categoria
- Página 404 para rotas inexistentes

## Estrutura

```
src/
├── components/   # Navbar, Footer, Card
├── data/         # lista de carros importados
├── pages/        # Home, Carros
├── App.jsx       # rotas da aplicação
└── main.jsx
```

## Como rodar

```bash
npm install
npm run dev
```
